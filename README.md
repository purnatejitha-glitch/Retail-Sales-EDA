# Retail Sales Data Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales performance, identify trends, examine data quality issues, and generate actionable business insights.

## 🎯 Objectives
- Analyze sales across different product categories.
- Compare sales performance across regions.
- Understand order status distribution.
- Explore date-wise sales trends.
- Identify missing values, duplicate records, inconsistent category names, and unusual sales values.
- Present findings through data visualizations.

## 🛠️ Technologies Used
- **Python**
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Development environment

## 📂 Dataset Information
The dataset contains 30 rows and 6 columns.

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Date | Date of the order |
| Region | Geographical sales region |
| Category | Product category |
| Sales | Sales amount |
| Status | Order status |

## 🔍 Analysis Performed
1. **Data Loading and Inspection:** Examined dataset dimensions, data types, and sample records.
2. **Data Cleaning:** Checked missing values, duplicate records, inconsistent category names, and negative sales values.
3. **Descriptive Statistics:** Calculated mean, median, mode, and standard deviation.
4. **Category Analysis:** Compared total sales across product categories.
5. **Regional Analysis:** Evaluated sales performance across regions.
6. **Order Status Analysis:** Examined the distribution of order statuses.
7. **Date-wise Sales Analysis:** Visualized sales trends over time.
8. **Business Insights:** Summarized findings to support data-driven decisions.

## 📊 Visualizations
The project includes:
- Bar chart of total sales by category
- Bar chart of total sales by region
- Order status distribution chart
- Line chart of date-wise sales trends

## 💡 Key Business Benefits
- Identifies strong and weak product categories.
- Helps compare regional sales performance.
- Supports sales monitoring and inventory planning.
- Highlights data quality issues that require further investigation.
- Helps businesses make informed decisions using data.

## 🧰 Tools and Skills Demonstrated
Python, Pandas, data cleaning, exploratory data analysis, descriptive statistics, data visualization, and business insight generation.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```

3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `Retail_Sales_EDA.ipynb`.
5. Ensure the CSV dataset is available in the correct folder.
6. Run all notebook cells.
